Neko Run

A free pixel cat runner by the Nekomo community. Dodge cucumbers and crows, grab fish for +25, and chase a high score. Play right here, or install it on Android, Windows or Linux.

Packages

The web game is also published to GitHub Packages, so you can embed it in your own site or host it yourself.

npm: @nekomo-app/neko-run

# .npmrc
@nekomo-app:registry=https://npm.pkg.github.com

npm install @nekomo-app/neko-run
<div data-neko-run data-prefix="mysite_"></div>
<script src="node_modules/@nekomo-app/neko-run/neko-run.js" defer></script>

Container: ghcr.io/nekomo-app/neko-run

docker run -p 8080:80 ghcr.io/nekomo-app/neko-run
# then open http://localhost:8080

How to play

Jump (hold for higher)Space / ↑ / WTap the game or Jump

Settings include sound and volume, difficulty (Easy / Normal / Hard, each with its own high score), five cat colours, Sakura or Night sky, effects, auto full screen and touch buttons. Everything is saved on your device; this page keeps its own high scores separate from the 404 page.
