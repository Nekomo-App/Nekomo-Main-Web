About this website

nekomoapp.netlify.app is the official, community-run website for Nekomo. It exists to host project information, APK downloads (Stable & Beta/Debug, Mobile & Android TV), release notes, contributor credits, and these support/legal pages in one place.

The site itself is a static, open-source page hosted on Netlify — its source lives at Nekomo-App/nekomo-main-web. It does not host, stream, or distribute any anime content; see the DMCA & Disclaimer Brand Assets page for details. The website is maintained by the same volunteer community that builds the app, not a company.

Frequently asked questions

Is Nekomo available on iOS?

No. Nekomo is an Android and Android TV app only.

Where do I download it?

Nekomo isn’t publicly released yet. For now, builds are only available on the Beta page. Only use official links, since third-party copies can be modified.

Is the app always downloadable, even if something's down?

Yes. Each build also has a permanent direct link (e.g. nekomoapp.netlify.app/Nekomo-phone-beta.apk) that downloads straight from GitHub and doesn’t depend on this site's own scripts or API calls working. If the Beta page's live list ever fails to load, use the direct link instead or grab it straight from the apks folder on GitHub.

Does Nekomo host videos?

No. It hosts nothing and operates no streaming servers. See the DMCA & Disclaimer Brand Assets.

Why do I have to sign in?

Nekomo uses AniList, MyAnimeList, or Kitsu for your profile and list. Nekomo has no accounts of its own. See the Privacy Policy.

Can you add a specific anime site or source?

Nekomo does not ship with any streaming sources by default, does not provide or recommend them, and can’t help find them. You install sources/extensions yourself, at your own discretion.

Is the app free?

Yes. Nobody on the team will ever ask you for money in DMs. Report anyone who does.

What's the background music on this website?

It's optional and off by default. Turn it on from the settings button (bottom-right gear icon), where you can also play/pause, adjust volume, or swap in your own YouTube link. See the Background Music & External Links disclaimer — licensing is your responsibility for any link you add.

Report a bug

Open a GitHub issue and include:

  • app version and build type (stable / beta / debug, phone / TV);
  • Android version and device model;
  • what you did, what you expected, and what happened (screenshots help);
  • the in-app error log: Settings → History → Error log can file a pre-filled issue for you. Remove anything private first.

Install & update help

  • “App not installed”: uninstall any other Nekomo build first. Release, beta, and debug builds use different package IDs and signatures, and builds signed with a different key cannot update each other.
  • Install blocked: allow “Install unknown apps” for your browser or file manager in Android settings.
  • Android TV: install the TV build; sideload using a file manager or adb install.
  • Minimum version: Android 5.0 (API 21) or newer.

Sign-in problems

  • Check that you can log in on the provider’s own website (AniList, MyAnimeList, Kitsu).
  • Complete the OAuth page in the browser and return to the app. If nothing happens, try again with a different default browser.
  • Try signing out and back in. Clearing app storage resets everything on the device.

Playback problems

  • Try a different source or quality, or retry after a minute, since third-party hosts go down often.
  • If a site fails to load for you, try enabling DNS-over-HTTPS in Settings → General.
  • Update to the latest build, then file a bug with the error log if it persists.

Extensions

The app does not come with any extensions or sources pre-installed — it's a blank client until you add some yourself. Extensions are made by third parties, and Nekomo cannot support, vouch for, or provide them. Install only from sources you trust (Settings → Extensions). If an extension misbehaves, disable or remove it first. Report problems to that extension’s author.
