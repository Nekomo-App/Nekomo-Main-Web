Sources & Extensions

Nekomo is a blank client. You choose, add and install every source yourself.

What is (and isn’t) included

Nekomo ships with no sources installed. Title information (names, artwork, descriptions, trailers) comes from built-in metadata services such as AniList; everything you can actually play or read comes from sources you add.

There is one optional official repository, the Nekomo Official Repository. It only lists free and legal sources and metadata APIs. Nothing is installed until you open Settings → Extensions, add a repository by URL or code, and confirm the third-party-code warning. You can remove it, and the sources it installed, at any time.

The repository only covers script/plugin sources (CloudStream .cs3, Zangetsu .js). APK extensions (Aniyomi, Mihon) are never downloaded, installed or updated automatically: you add those repositories and install the APKs yourself. Nekomo does not host or vouch for any other repository; only add ones you trust.

Supported source types

  • CloudStream — .cs3 plugins from a repo.json repository.
  • Zangetsu — JavaScript sources from an index.json repository.
  • Aniyomi — anime extension APKs from an index.min.json repository.
  • Mihon — manga extension APKs from an index.min.json or index.pb repository. Manga is read under Settings → Manga.

LN Reader (novel) plugins are not supported yet.

Add a repository & install

  • Open Settings → Extensions and scroll to the section for the type you want. Each section starts empty.
  • Paste the repository URL you trust and tap Add. Confirm the warning.
  • Tap Browse on that repository to see what it offers, pick an extension and confirm the install. You are asked every time.
  • Installed items appear under “Installed” where you can enable, update, report or uninstall them.

Choosing a source

  • On any title page, tap the cloud icon (Choose source) to search that title in one of your installed sources and open the match.
  • A catalogue title with no episodes opens the chooser for you automatically.
  • In the player, the Source menu switches between the links the source returned.

Content filters (18+, movies & TV)

Both switches live in Settings → General and are off by default.

  • Show movies and TV shows — off keeps Nekomo anime-only: sources that provide movies or series are hidden from lists, search and the source chooser. Turn it on to see them.
  • Show 18+ sources and extensions — adult content is allowed, but hidden until you opt in. Turning it on asks you to confirm you are 18 or older (or the age of majority where you live). It reveals adult extensions in repository lists and lets search include adult titles.

If a repository looks empty after you browse it, its entries may be hidden by these filters; Nekomo tells you how many.

Staying safe

  • Extensions are third-party code that runs with the app’s permissions. A malicious one can read data the app can and use the network. Only install from authors you trust.
  • Use the Report button on an installed extension to open its author’s issue tracker. Nekomo cannot fix or moderate third-party extensions.
  • You are responsible for what you install and access. See the Terms and the DMCA notice.

Troubleshooting

  • A repository won’t add or is empty: check the URL opens in a browser and points at the index file itself. Mihon repositories now often publish index.pb instead of index.min.json.
  • Searches or streams fail: the source site may be down or blocked by your network or DNS filter. Try Settings → General → DNS over HTTPS, or another source.
  • An extension won’t load: it may need a newer Nekomo. Nekomo requires Android 7.0 or newer, and extensions built for much newer APIs can fail; update the app and the extension.
  • Still stuck? See Support and include the error log from Settings → History.
