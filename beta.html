Beta & Alpha Builds

Help test upcoming Nekomo changes. Every APK in the apks folder of the Nekomo-App/Neko-Source repository is listed here automatically.

Heads up: these are unfinished test builds for people who want to help find bugs. They can crash, break, or lose app data. Do not rely on them as your main app, and read the Terms first. A public stable release isn’t available yet, so this page is currently the only place to get Nekomo.

Install with care

Allow “Install unknown apps” for your browser or file manager. Debug, beta, and release builds are separate apps with different signatures.

Official source only

This list is pulled live from the apks folder of Nekomo-App/Neko-Source. Never install copies from elsewhere.

Report what you find

Open a GitHub issue with your version, device, and the in-app error log.

Direct links

Every build also has a permanent short link, e.g. nekomoapp.netlify.app/Nekomo-phone-release.apk — visiting it downloads the APK immediately, no page in between.
